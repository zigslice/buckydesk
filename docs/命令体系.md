# 命令体系

命令行和 `http://127.0.0.1:1016` 上的页面调用同一棵命令树。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/backend` | Rust 命令树、命令行入口、本机 HTTP、内核管理、身份激活 |
| `src/frontend` | gd5 页面。`index.html` 由 `/` 提供，其余文件由 `/app/` 提供 |
| `src/frontend/vendor/gd5` | [gd5](https://github.com/zigslice/gd5) 子模块 |

## 两个面

每条命令带一个面：

| 面 | 含义 |
| --- | --- |
| `cli` | 只在终端运行（如 server、kernel start/stop、identity activate） |
| `http` | 只从页面运行 |
| `both` | 两边都能运行（如 kernel status、identity status、product info） |

`server` 是 `cli`。页面所在的进程不能再把自己启动一次。页面请求它时，HTTP 返回 403，摘要说明只能在命令行运行。

终端入口是 `buckydesk <命令>`。页面先 `GET /api/commands` 拿到同一棵树，再 `POST /api/exec`，正文是 `{"argv":["kernel","status"]}`。`argv` 不含程序名。

## 树

```
buckydesk
  version                 打印版本和 BUCKYOS_ROOT
  commands                打印命令树
  server                  监听并打开浏览器          cli
    --bind <值>           默认 127.0.0.1:1016
    --no-open             不打开浏览器
    --frontend <值>       页面目录
    --gd5 <值>            gd5 目录
  kernel
    status                查看内核运行状态          both
    start                 拉起内核进程              cli
    stop                  停止内核进程              cli
  identity
    status                查看身份文件状态          both
    activate              激活本机身份              cli
      --name <值>         显示名称（必填）
      --password <值>     管理员密码（必填，至少8位）
      --zone <值>         Zone名称（可选）
  product
    info                  查看产品配置              both
```

选项只有 `--name` 和 `--name=值`。没有位置参数。未知命令、未知选项退出码 2。命令跑完但 `ok` 为 false，或者明确失败，退出码 1。成功是 0。

## 内核状态

`kernel status` 返回的 `state` 字段可能的值：

| state | 说明 |
| --- | --- |
| `not_installed` | 内核未安装 |
| `unactivated` | 待激活 |
| `stopped` | 内核已停止 |
| `starting` | 内核启动中 |
| `running` | 内核运行中 |
| `error` | 内核错误 |

## 身份状态

`identity status` 返回的 `status` 字段可能的值：

| status | 说明 |
| --- | --- |
| `not_installed` | 内核未安装 |
| `unactivated` | 待激活 |
| `partial` | 激活未完成 |
| `configured` | 已配置 |
| `invalid` | 配置无效 |

## 产品模式

BuckyDesk 默认使用 Lite 模式，配置存储在 `$BUCKYOS_ROOT/etc/product.json`：

```json
{
  "edition": "lite",
  "capabilities": {
    "container": false,
    "user_service_apps": false,
    "static_web_apps": true,
    "max_running_agents": 1
  }
}
```

## 页面能拿到的路径

| 路径 | 来源 |
| --- | --- |
| `/`、`/index.html` | `src/frontend/index.html` |
| `/app/*` | `src/frontend` 下的页面脚本和样式 |
| `/gd5/*` | gd5 源码，供 ESM 直接加载 |
| `GET /api/commands` | 命令树 JSON |
| `POST /api/exec` | 按 `argv` 在 http 面分发 |

路径会做百分号解码。带 `..` 的路径不读文件。请求正文上限 64KB，响应带 `Connection: close`。

## 本地开发

```bash
cargo run -p buckydesk -- server
```

Linux 上 1016 端口需要额外权限，可以用 `--bind 127.0.0.1:18016`。
